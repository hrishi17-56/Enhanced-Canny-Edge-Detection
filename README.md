# Enhanced Canny Edge Detection Algorithm

## 📌 Project Overview

The Enhanced Canny Edge Detection Algorithm is a Python-based image processing project that focuses on identifying edges and boundaries in digital images. It aims to improve edge detection by applying image processing techniques to reduce noise and produce clearer edge maps.

## 🎯 Objectives

- Detect important edges in images.
- Reduce unwanted noise.
- Improve edge clarity.
- Compare traditional and enhanced Canny edge detection.
- Study the effectiveness of image processing techniques.

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd canny_enhanced_project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the main Python file:

```bash
python main.py
```

Replace `main.py` with your actual entry-point filename if necessary.

## 🔄 Project Workflow

1. Input Image
2. Image Preprocessing
3. Noise Reduction
4. Gradient Calculation
5. Non-Maximum Suppression
6. Double Thresholding
7. Edge Tracking by Hysteresis
8. Final Edge Detection Output
